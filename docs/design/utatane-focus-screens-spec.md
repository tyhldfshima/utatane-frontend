## 1. 重点画面と選んだ理由

4導線と「自分」から、次の3つの条件のどれかに当たる画面を選んだ。
- 利用者が迷う
- 取り違える
- ポイントが動く、または取り返しがつかない

| 記号 | 画面 | 導線 | 選んだ理由 |
|---|---|---|---|
| A | 歌の画面（ありがとう・参加・育てる） | ①② | 「この歌の制作に参加する」と「新しい Version として育てる」を取り違えやすい。ありがとうのボタンの出し分け（Y4 暫定・自分も届け先）がここに集まる |
| B | この歌の制作に参加する（何で参加するか → 送る） | ① | 公開された歌への参加は、元の歌ではなく新しい制作に入る（U3）。何で参加するか（歌う人だけではない）と、送った物がまだ入っていないことが伝わらないと取り違える |
| C | ありがとう：量を選ぶ | ② | ポイントが動く入口。残高の古さ・足りない・前の贈与の結果待ちで迷う |
| D | ありがとう：贈る前の確認 | ② | 取り返しがつかない（利用者は取り消せない＝T6）。確認はここで1回 |
| E | ありがとう：結果 | ② | 通信が切れたときの「結果を確認しています」で、二重に贈る心配が出る |
| F | 公開する前の確認（参加者の同意） | ③ | 「同意」と「公開」を取り違えやすい。届け方をここで初めて見る |

| H | 取引の詳細（point.ty-hld.com） | ② の後 | ポイントの記録。見せてよい物・見せない物の決まり（えふさん確定）が一番効く |

## 2. 全画面に共通の決まり

### 2-1 押しやすさ・迷わせない作り

- 押せる物の高さ：
  - 主ボタン・ボタン：52px
  - 小さなボタン・文字のリンク・戻る：44px 以上
  - 量の札：52px
  - 試作の全60状態で、44px 未満の押せる物は0（Playwright で測った）。
- 主ボタンは1画面に1つ。試作の全60状態で、2つ以上ある状態は0。
- 取り返しのつかない操作の前には、確認を1回だけ置く：
  - 贈る：D が確認の画面そのもの。［贈る］を押したら、そのまま送る
  - 公開する：G の確認の小窓
  - 公開に同意する：F の確認の小窓（公開前なら、同意はやめられる）
- 戻る道を必ず置く：
  - 通常のページ：左上の「戻る」
  - シート：［閉じる］［戻る］［やめる］
  - 押せない状態でも、戻る道は残す
- 押した直後の決まり：［贈る］［参加する］［公開する］は、押した直後に押せない状態へ変え、何をしているかを文字で出す（例：「贈っています」）。二重押しを防ぐ（T8）。
- 状態は色だけで伝えない。文字・形・アイコンを合わせて使う：
  - 押せないボタン：灰色の面と、理由の1行
  - 量の増減：「−300 TYP」と「あなたの TYP が減りました」
- 読み上げ：
  - 結果・状態の変化を読み上げに伝える（role=status・role=alert）。
  - 札（暫定・見本・仮の形）と「Y4 の差し込み口」の文字は、設計の印。本番の画面には出さない。

### 2-3 Y4 暫定の外し方

- 「ありがとうを贈る」の利用不可（受け取れない方がいる歌）は、1つの条件だけで出し分ける。条件は「Y4 の本番受入の前か後か」。
- 画面の中に、条件の分かれ道を別々に作らない。この条件は、A の出し分け・C の前の確かめ・D の注意の1行の3か所で同じ物を見る。
- Y4 の本番受入に PASS したら、次の2つを1回で切り替えられる作りにする：
  - A の利用不可の状態を出さなくなる。
  - D・E・H に「受け取れない方の分は送られず、あなたのTYPからも減りません」を出す（えふさん確定：表記は「TYP」で統一）。
- 条件をどこに持つかは、実装の便で決める（この設計では決めない）。
- 「自分も届け先に入っている」ための利用不可（941be1bd 3）は恒久の決まり。Y4 とは別の条件にする。

この歌をつくった人（えふさん確定 ①）：
- そのVersionで採用され、表示対象になっている Contribution を、役割付きで全員出す（作詞・作曲・編曲・ボーカル・ギター・ピアノ・MIX など、実際に採用された人）。
- 同じ人が複数なら1行にまとめる（例：「あさひさん　歌詞・作曲」）。
- 採用されていない提出物・表示の対象から外れた貢献の人は出さない。
- 人物を足さない（「歌がある以上、作曲者がいるはず」と画面で作らない）。歌詞だけの種なら、歌詞の人だけが出る。外部素材・権利情報など Contribution 以外の由来は、この欄に人として混ぜない。

2つの枠（取り違えを防ぐ・えふさん確定 ②④）：
- 「この歌の制作に参加する」（募集があるときだけ出す）：「あさひさんが一緒につくる仲間を募集しています。」「募集中：ギター・コーラス」［参加する］。募集内容を先に見せる。募集がないときは枠ごと出さない。
- 「新しい Version として育てる」（募集とは独立・いつも出す）：「この歌の一部を受け継いで、あなたが主催する新しい Version をつくります。」
- 言い分け：参加する＝今の主催者の制作に、募集されている役割で加わる。新しい Version として育てる＝元の Version から使いたい Contribution を選び、自分が主催する別の Version を始める。

### B この歌の制作に参加する（何で参加するか → 送る → 送りました）

えふさん確定 ②③：［参加する］を押した後に、募集されている役割から「何で参加するか」を選ぶ（例：「ギターで参加」「コーラスで参加」）。参加する＝歌う人専用ではない。送った物は、主催が入れるまで Contribution に確定しない。

えふさん確定（追補・2026-09-19）：募集の役割が1つなら、選択画面を省く。その役割を自動で選んで「送る」へ進む。省くのは選ぶ操作だけで、送る・送りました・制作中の歌の画面には「作曲で参加」のように参加している役割を必ず出す。募集が複数なら今までどおり選ぶ。募集が1つのときの「戻る」は歌の画面へ（自動で進む画面へ戻り続けないため）。

| 状態 | 出す物と文言 | 主ボタン |

| 募集が1つ（選ぶ操作を省く） | 選択画面を出さず、自動で選んだ役割で「送る」を出す。見出し「この歌の制作に参加する」・印「作曲で参加」・「ひなたさんの制作に加わります。いま募集しているのは「作曲」なので、作曲で参加します。」・制作の題名 | 作曲を送る |

### J 新しい Version として育てる（何を受け継ぐか → 何を加えるか）
